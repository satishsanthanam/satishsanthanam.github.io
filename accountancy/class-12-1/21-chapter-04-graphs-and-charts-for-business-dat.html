Class 12 (Part 1) — Chapter 4: Graphs and Charts for Business Data

Introduction to Graphs and Charts

In accounting, presenting a mass of raw data can make it difficult to understand. Visual representations help communicate accounting information effectively, following the adage, A picture is worth more than a thousand words. This chapter explains how to prepare graphs, charts, and diagrams using spreadsheet software like MS Excel.

What are Graphs and Charts?

A graph is a pictorial representation of data showing at least a two-dimensional relationship using axes:

  • X-axis: The horizontal axis, usually representing independent categories.
  • Y-axis: The vertical axis, usually representing dependent values.

Common types of visual representations include:

  • Line Graph: Can be single-line or multiple-line (using different colors/shades for clarity).
  • Pie Chart: Represents multiple sub-groups of a single variable.
  • Bar Diagram: Depicts and compares two or more variables.
Basic Steps for Creating Charts in Excel

Creating a chart in MS Excel involves entering data and selecting the appropriate chart type from the Ribbon interface.

Step-by-Step Chart Creation
  1. Step 1 (Data Entry): Enter the accounting or sales data into a worksheet with proper row and column headers.
  2. Step 2a (Selection): Select the specific data range to be plotted (e.g., product-wise totals).
  3. Step 2b (Insertion): Go to the Insert tab on the Ribbon, navigate to the Charts group, and select the desired chart type (e.g., Bar, Line, Pie).

Key Elements of a Chart

Understanding chart elements is essential for effective formatting and customization:

  1. Chart Area: The entire chart window including all of its elements.
  2. Plot Area: The area bounded by the axes (X and Y for 2D charts; X, Y, and Z for 3D charts).
  3. Data Points: Individual values plotted in the chart, represented by data markers (bars, lines, columns, or pie slices). A collection of related data points forms a data series.
  4. Axes: The horizontal category axis (X-axis) and vertical value axis (Y-axis).
  5. Legend: An index or key that identifies the data series or categories.
  6. Chart and Axes Titles: Descriptive text labels for the chart and its individual axes.
  7. Data Labels: Labels that provide additional details about individual data markers.
Formatting and Customizing Charts

Once a chart is created, Excel provides Chart Tools containing three main tabs: Design, Layout, and Format.

Using the Design Option

The Design tab allows users to change the overall look of the chart:

  • Change the chart type, layout, or style.
  • Swap data axes using the Switch Row/Column command (e.g., changing the X-axis from products to quarters).

Changing the Format of Chart Elements

The Format tab provides options to customize individual elements:

  • Shape Styles: Modify Shape Fill (solid colors, gradients, textures, or pictures), Shape Outline (color, weight, dashed lines), and Shape Effects (bevel, shadow, reflection).
  • Text Formatting: Apply standard font formatting or WordArt Styles (text fill, outline, shadow, 3D effects).

Changing the Layout

The Layout tab allows users to insert additional elements such as clip art, pictures, shapes, text boxes, data labels, and gridlines.

Chart Types and Dimensionality

Pie Charts

A Pie Chart represents the relative size of parts to a whole. It has specific constraints:

  • Only plots a single data series.
  • All data values must be positive and non-zero.
  • Ideally limited to a maximum of seven categories for readability.

2D vs. 3D Charts
  • 2D Charts: Plotted on two axes (X and Y). Examples include line, bar, area, column, scatter (XY), and bubble charts. Negative values are plotted on the opposite side of the origin ($O$).
  • 3D Charts: Feature a third axis, the depth axis (Z-axis or series axis), allowing data to be plotted along the depth of the chart.

Specialized Charts
  • Radar Chart: Compares aggregate values of multiple data series. It does not have standard horizontal category axes.
  • Doughnut Chart: Similar to a pie chart but can contain multiple data series represented as concentric rings.
Advantages of Using Graphs and Charts

Visualizing business and accounting data offers several key benefits:

  • Help to Explore: Allows quick identification of relationships, trends, and correlations between variables (e.g., GNP and infant mortality, or sales trends over time) without parsing raw tables.
  • Help to Present: Delivers complex information rapidly and clearly, which is highly useful in media, reports, and executive summaries.
  • Help to Convince: Simplifies large volumes of data into persuasive visual evidence to support business decisions.
