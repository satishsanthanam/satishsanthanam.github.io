Computer Science: Class 11 — Chapter 1: Computer System

1.1 Introduction to Computer System

A computer system is an electronic device programmed to accept data (input), process it, and generate results (output). It comprises both hardware and software components functioning together as a single unit to deliver the desired output.

"A computer would deserve to be called intelligent if it could deceive a human into believing that it was human."

Literary Interpretation & Contextual Significance: This famous quote by Alan Turing highlights the foundational philosophy of Artificial Intelligence (AI) and the Turing Test, emphasizing the benchmark of human-like cognitive deception as the ultimate measure of machine intelligence.

Literary Profile: Alan Turing

  • Traits & Temperament: Visionary mathematician, logician, and pioneer of theoretical computer science.
  • Socio-Economic & Contextual Background: Worked during the mid-20th century, notably breaking wartime codes at Bletchley Park and establishing the theoretical framework for modern digital computers.
  • Thematic & Symbolic Motifs: Computation limits, machine intelligence, algorithmic decidability, and the mechanization of thought.
1.1.1 Central Processing Unit (CPU)

The Central Processing Unit (CPU) is the electronic circuitry of a computer that carries out the actual processing and is commonly referred to as the brain of the computer. It is physically fabricated on one or more microchips called integrated circuits (ICs) made of semiconductor materials.

  • Arithmetic Logic Unit (ALU) : Performs all arithmetic operations (addition, subtraction, multiplication, division) and logical decisions (comparisons).
  • Control Unit (CU) : Controls sequential instruction execution, interprets instructions, and guides the flow of data through the computer's memory, ALU, and input/output devices.
  • Registers : High-speed, extremely limited local memory locations inside the CPU chip used to store temporary data, instructions, or intermediate results during processing.
1.1.2 Input Devices

Devices through which control signals and raw data are sent to a computer. They convert physical input into digital signals acceptable by the computer system.

  • Keyboard : Standard \text entry device, including specialized braille keyboards for the visually impaired.
  • Mouse : Point-and-click graphical navigation device.
  • Scanner : Converts physical documents and images into digital formats.
  • Touch Screen : Dual-purpose input/output interface common in smartphones and tablets.
  • Voice Input : Captures spoken audio to process search queries or commands (e.g., Google voice search).
1.1.3 Output Devices

Devices that receive processed digital data from a computer system and convert it into human-understandable or physical forms.

  • Display Monitor : Visual screen interface showing \text, graphics, and video.
  • Printer : Produces hardcopy output. Common types include inkjet, laserjet, and dot matrix.
  • 3D Printer : Builds physical replicas of digital 3D designs, widely used in manufacturing and medical organ prototyping.
  • Speaker & Headphones : Convert digital audio signals into audible sound waves.
  • Braille Display Monitor : Assists visually challenged users in reading textual output dynamically.
1.2 Evolution of Computer

Computing devices have evolved rapidly from simple mechanical calculators to modern, high-performance multi-core processors.

Key Milestones in Computing History
Era / Year Invention Key Features & Significance
500 BC Abacus Mechanical device capable of simple arithmetic calculations using beads on rods.
1642 Pascaline Invented by Blaise Pascal; mechanical calculator performing direct addition/subtraction and repeated multiplication/division.
1834 Analytical Engine Designed by Charles Babbage; mechanical computing device featuring input, processing, storage, and output, forming the basis of modern computers.
1890 Tabulating Machine Designed by Herman Hollerith; used punched cards to summarize data, marking a major step toward programming.
1937 Turing Machine Theoretical general-purpose programmable machine capable of solving any problem by executing instructions stored on punched cards.
1945 EDVAC / ENIAC Based on John von Neumann's stored-program concept, allowing both data and programs to be stored in memory.
1947 Transistor Developed at Bell Labs; replaced bulky vacuum tubes, drastically reducing computer size and power consumption.
1970 Integrated Circuit (IC) Silicon chip containing an entire electronic circuit on a tiny area, leading to massive miniaturization.
Von Neumann Architecture & Moore's Law

The Von Neumann Architecture consists of a CPU (containing an ALU and CU), memory, input/output devices, and communication channels. The Electronic Numerical Integrator and Computer (ENIAC) was the first binary programmable computer based on this architecture.

Scientific Profile: Gordon Moore & Moore's Law

  • The Law (1965): Predicted that the number of transistors on a microchip would double approximately every two years, while the cost of computers would be halved.
  • Technological Eras: Transitioned from Large Scale Integration (LSI) in the 1970s to Very Large Scale Integration (VLSI) in the 1980s (integrating ~3 million components), and later to Super Large Scale Integration (SLSI) fabricating over 100 million components on a single IC.
1.3 Computer Memory

Memory is required to store data and instructions for processing. It is broadly categorized into primary memory, cache memory, and secondary memory.

1.3.1 Units of Memory

Computers use binary numbers (0 and 1) to store and process data. The basic units of memory are:

  • Bit : Binary digit (0 or 1).
  • Nibble : A group of 4 bits (e.g., 1001).
  • Byte : A group of 8 bits (e.g., 01000110).

1.3.2 Types of Memory
  • Primary Memory : Directly accessed by the CPU. It includes:
    • RAM (Random Access Memory) : Volatile memory that temporarily stores active programs and data. Contents are lost when power is turned off.
    • ROM (Read Only Memory) : Non-volatile memory used for permanent storage of critical startup programs (e.g., the boot loader).
  • Cache Memory : Extremely high-speed memory placed between the CPU and primary memory to store copies of frequently accessed data, reducing average access time.
  • Secondary Memory : Non-volatile, high-capacity, and cheaper storage used for permanent data retention. Examples include Hard Disk Drives (HDD), Solid State Drives (SSD), CDs, DVDs, and Pen Drives.
1.4 Data Transfer between Memory and CPU

Data must be transferred continuously between the CPU, primary memory, and secondary storage. This transfer is achieved using physical wires called buses .

  • Data Bus : Bidirectional bus used to transfer actual data between different components.
  • Address Bus : Unidirectional bus used by the CPU to specify the physical memory address it wants to read from or write to.
  • Control Bus : Unidirectional bus used to transmit control signals (such as read/write commands) between components.
  • System Bus : The collective term for the Data, Address, and Control buses.
  • Memory Controller : Dedicated hardware that manages the flow of data into and out of the computer's main memory.
1.5 Microprocessors & Microcontrollers
1.5.1 Microprocessor Specifications

A microprocessor is a CPU fabricated on a single integrated circuit chip. Its performance is determined by:

  • Word Size : The maximum number of bits a processor can process at a single time (ranging historically from 4/8 bits to modern 64-bit architectures).
  • Memory Size : The maximum RAM capacity supported, which depends directly on the processor's word size (up to 16 Exabytes for 64-bit systems).
  • Clock Speed : The frequency of internal pulses generated by the computer's clock, measured in Gigahertz (GHz), indicating how many billions of instructions can be executed per second.
  • Cores : Individual, independent execution units within a single CPU chip (e.g., dual-core, quad-core, octa-core).
1.5.2 Microcontrollers

A microcontroller is a small, low-cost computing device that integrates a CPU, a fixed amount of RAM, ROM, and input/output ports all onto a single chip. Unlike general-purpose microprocessors, microcontrollers are designed for specific, dedicated tasks in embedded systems (e.g., washing machines, digital cameras, microwaves, and remote controllers).

1.6 Data and Information

Data represents raw, unorganized, and unprocessed facts, whereas information is processed, structured, and meaningful data.

1.6.1 Data Types
  • Structured Data : Follows a strict, pre-defined tabular format organized in rows and columns (e.g., database tables, student attendance records).
  • Unstructured Data : Lacks a pre-defined record format or structure, consisting of mixed \text, graphics, and media (e.g., audio/video files, social media posts, satellite images).
  • Semi-structured Data : Lacks a rigid tabular structure but contains internal tags, markers, or organizational elements to separate data fields (e.g., XML files, HTML pages, CSV files).
1.6.2 Data Lifecycle & Security
  1. Data Capturing : Gathering raw data from digital sources (e.g., keyboards, barcode scanners, remote sensors).
  2. Data Storage : Retaining captured data on digital storage devices or high-capacity data servers.
  3. Data Retrieval : Fetching stored data from databases for active processing.
  4. Data Deletion and Recovery : Deleting data typically marks its address space as free without immediately erasing the bits. Data recovery is the process of retrieving deleted or corrupted data before it is overwritten by new data.
1.7 Software

Software is a set of instructions (programs) that operates the physical hardware components of a computer system.

1.7.2 System Software

Provides the core functionality required to operate and maintain the computer hardware directly.

  • Operating System (OS) : The fundamental system software that manages hardware resources and provides a platform for application software.
  • System Utilities : Software used for system maintenance and configuration (e.g., disk defragmenters, anti-virus tools, disk compressors).
  • Device Drivers : Specialized programs that act as translators between the operating system and specific hardware peripherals (e.g., printers, scanners).
1.7.3 Programming Tools

Tools used by developers to write, translate, and test computer programs.

  • Low-level Languages : Machine-dependent languages, including machine language (binary 1s and 0s) and assembly language (using mnemonics).
  • High-level Languages : Machine-independent, human-readable languages (e.g., Python, Java, C++).
  • Language Translators :
    • Assembler : Converts assembly language into machine code.
    • Compiler : Translates the entire high-level source code into machine code at once, producing an executable file.
    • Interpreter : Translates and executes high-level source code line-by-line in real-time.
  • Integrated Development Environment (IDE) : A comprehensive software suite combining a \text editor, build tools, and a debugger (e.g., Python IDLE, Eclipse, NetBeans).
1.7.4 Application Software & Licensing
  • General Purpose Software : Developed for generic, widespread applications (e.g., word processors, web browsers, spreadsheets).
  • Customised Software : Tailor-made to meet the specific requirements of an individual or organization (e.g., school management systems, accounting software).
  • Proprietary Software : Software owned by a vendor who restricts access to the source code and requires purchase (e.g., Microsoft Windows, Tally).
  • Free and Open Source Software (FOSS) : Software whose source code is freely accessible, modifiable, and distributable (e.g., Ubuntu, Python, LibreOffice).
  • Freeware : Software available free of charge, though its source code remains closed and proprietary (e.g., Skype, Adobe Reader).
1.8 Operating System

The Operating System (OS) acts as a resource manager that controls and coordinates hardware, system security, and application software execution.

1.8.1 OS User Interfaces
  • Command-based Interface (CLI) : Requires users to type \text commands to perform tasks; less interactive and runs one program at a time (e.g., MS-DOS, Unix).
  • Graphical User Interface (GUI) : Allows users to interact using visual icons, menus, and windows via a mouse and keyboard (e.g., Windows, macOS).
  • Touch-based Interface : Responds to physical touch inputs on screens (e.g., Android, iOS).
  • Voice-based Interface : Operates using spoken voice commands (e.g., Siri, Cortana, Google Assistant).
  • Gesture-based Interface : Detects physical movements such as waving, tilting, or eye motion (used in gaming and medical applications).
1.8.2 Functions of the Operating System
  1. Process Management : Allocates CPU time among multiple active processes, ensuring efficient execution and scheduling.
  2. Memory Management : Dynamically allocates and deallocates primary memory (RAM) to running processes.
  3. File Management : Manages the creation, deletion, organization, and access control of files in secondary storage.
  4. Device Management : Coordinates and controls peripheral devices through their respective device drivers.
