Computer Science: Class 12 — Chapter 5: Sorting

5.1 Introduction to Sorting

Sorting is the fundamental computational process of ordering or arranging a given collection of elements in a specific, predictable sequence. Sorting is a cornerstone of computer science, optimizing search operations and data retrieval pipelines.

Real-World and Computational Examples
  • Numerical Sorting : Arranging a list of numbers in ascending (increasing) or descending (decreasing) order.
  • Lexicographical Sorting : Arranging strings in alphabetical order (a-z or z-a) or according to string length (e.g., words in a dictionary).
  • Physical/Logistical Sorting : Assigning examination hall seats based on candidate roll numbers, or sorting students by height or weight.
The Search Efficiency Trade-off

Searching through an unsorted collection requires a linear scan, which is highly inefficient ($O(n)$ complexity). Sorting the collection beforehand introduces an initial computational overhead but drastically reduces subsequent search \times (e.g., enabling Binary Search with $O(\log n)$ complexity).

5.2 Bubble Sort

Bubble Sort is a simple, comparison-based sorting algorithm. It operates by repeatedly stepping through the list, comparing adjacent elements, and swapping them if they are in the incorrect order. This process is repeated until the list is fully sorted.

Operational Mechanics
  • Pass : A single complete iteration through the unsorted portion of the list.
  • For a list of size $n$, Bubble Sort requires a maximum of $n - 1$ passes to guarantee a sorted state.
  • In each pass, the largest unsorted element "bubbles up" to its correct terminal position. Consequently, the unsorted sublist size decreases by 1 in each successive pass.
Algorithm 5.1: Bubble Sort 
  
    BUBBLESORT(numList, n)
    Step 1: SET i = 0
    Step 2: WHILE i < n REPEAT STEPS 3 to 8
    Step 3:   SET j = 0
    Step 4:   WHILE j < n - i - 1 REPEAT STEPS 5 to 7
    Step 5:     IF numList[j] > numList[j+1] THEN
    Step 6:       swap(numList[j], numList[j+1])
    Step 7:     SET j = j + 1
    Step 8:   SET i = i + 1
Program 5-1: Python Implementation of Bubble Sort 
  
    def bubble_Sort(list1):
    n = len(list1)
    for i in range(n):
    # Last i elements are already sorted, so we skip them
    for j in range(0, n - i - 1):
    if list1[j] > list1[j+1]:
    # Swap adjacent elements
    list1[j], list1[j+1] = list1[j+1], list1[j]
    numList = [8, 7, 13, 1, -9, 4]
    bubble_Sort(numList)
    print("The sorted list is :", numList)
Optimization: Early Termination

In standard Bubble Sort, even if the list becomes sorted before completing $n-1$ passes, the algorithm continues executing redundant passes. We can optimize this by introducing a boolean flag to track whether any swaps occurred during a pass. If no swaps occur, the list is already sorted, and we can break early. 

  
    def optimized_bubble_sort(list1):
    n = len(list1)
    for i in range(n):
    swapped = False
    for j in range(0, n - i - 1):
    if list1[j] > list1[j+1]:
    list1[j], list1[j+1] = list1[j+1], list1[j]
    swapped = True
    if not swapped:
    break # Exit early if no elements were swapped

Technical Profile: Bubble Sort

  • Architecture Layer / Tier: Comparison-based, in-place, stable sorting algorithm.
  • Operational Mechanics & Syntax: Iterative adjacent comparisons with immediate swapping. Uses nested loops where the inner loop boundary shrinks dynamically ($n - i - 1$).
  • System Trade-offs & Failures: Highly inefficient for large datasets ($O(n^2)$ worst and average-case time complexity). Performs excessive write/swap operations compared to Selection Sort.
5.3 Selection Sort

Selection Sort improves upon Bubble Sort by minimizing the total number of swaps. It divides the input list into two parts: a sorted sublist at the left and an unsorted sublist at the right.

Operational Mechanics
  1. Initially, the sorted sublist is empty, and the unsorted sublist contains all elements.
  2. In each pass, the algorithm scans the unsorted sublist to find the minimum element.
  3. The found minimum element is then swapped with the leftmost element of the unsorted sublist, making it part of the sorted sublist.
  4. This process repeats for $n - 1$ passes, reducing the unsorted sublist size by 1 in each pass.
Algorithm 5.2: Selection Sort 
  
    SELECTIONSORT(numList, n)
    Step 1: SET i = 0
    Step 2: WHILE i < n REPEAT STEPS 3 to 11
    Step 3:   SET min = i, flag = 0
    Step 4:   SET j = i + 1
    Step 5:   WHILE j < n REPEAT STEPS 6 to 10
    Step 6:     IF numList[j] < numList[min] THEN
    Step 7:       min = j
    Step 8:       flag = 1
    Step 9:     IF flag = 1 THEN
    Step 10:      swap(numList[i], numList[min])
    Step 11:  SET i = i + 1
Program 5-2: Python Implementation of Selection Sort 
  
    def selection_Sort(list2):
    n = len(list2)
    for i in range(n):
    min_idx = i
    flag = 0
    for j in range(i + 1, n):
    if list2[j] < list2[min_idx]:
    min_idx = j
    flag = 1
    if flag == 1:
    # Swap the found minimum element with the first element of unsorted part
    list2[i], list2[min_idx] = list2[min_idx], list2[i]
    numList = [8, 7, 13, 1, -9, 4]
    selection_Sort(numList)
    print("The sorted list is :", numList)

Technical Profile: Selection Sort

  • Architecture Layer / Tier: Comparison-based, in-place, unstable sorting algorithm.
  • Operational Mechanics & Syntax: Scans the unsorted partition to locate the absolute minimum element, then performs a single swap per pass to place it in the sorted partition.
  • System Trade-offs & Failures: Guarantees a maximum of $O(n)$ swaps, making it highly efficient when write operations are expensive. However, it still requires $O(n^2)$ comparisons regardless of whether the input is already sorted.
5.4 Insertion Sort

Insertion Sort is an intuitive sorting algorithm that builds the final sorted array one element at a time. It is highly analogous to the way a human sorts a hand of playing cards.

Operational Mechanics
  • The list is conceptually split into a sorted and an unsorted region.
  • In each pass, the first element of the unsorted region (the key/temp) is selected.
  • The algorithm traverses the sorted region backward, shifting all elements larger than the key one position to the right to make space.
  • The key is then inserted into its correct relative position.
Algorithm 5.3: Insertion Sort 
  
    INSERTIONSORT(numList, n)
    Step 1: SET i = 1
    Step 2: WHILE i < n REPEAT STEPS 3 to 9
    Step 3:   temp = numList[i]
    Step 4:   SET j = i - 1
    Step 5:   WHILE j >= 0 and numList[j] > temp REPEAT STEPS 6 to 7
    Step 6:     numList[j+1] = numList[j]
    Step 7:     SET j = j - 1
    Step 8:   numList[j+1] = temp
    Step 9:   SET i = i + 1
Program 5-3: Python Implementation of Insertion Sort 
  
    def insertion_Sort(list3):
    n = len(list3)
    for i in range(1, n):
    temp = list3[i]
    j = i - 1
    # Shift elements of list3[0..i-1] that are greater than temp
    while j >= 0 and temp < list3[j]:
    list3[j+1] = list3[j]
    j = j - 1
    list3[j+1] = temp
    numList = [8, 7, 13, 1, -9, 4]
    insertion_Sort(numList)
    print("The sorted list is :", numList)

Technical Profile: Insertion Sort

  • Architecture Layer / Tier: Comparison-based, in-place, stable, adaptive sorting algorithm.
  • Operational Mechanics & Syntax: Incremental insertion via backward shifting. Employs a nested loop structure where the inner loop terminates early if the correct insertion point is found.
  • System Trade-offs & Failures: Highly efficient for small or nearly-sorted datasets ($O(n)$ best-case time complexity). However, worst-case performance is $O(n^2)$ due to the high cost of shifting elements.
5.5 Time Complexity of Algorithms

Time complexity is a computational metric that quantifies the amount of time an algorithm takes to run as a function of the length of the input data ($n$).

Estimating Time Complexity
  • Constant Time ($O(1)$) : Algorithms without loops. The number of execution steps remains constant regardless of data size.
  • Linear Time ($O(n)$) : Algorithms containing a single loop running from $1$ to $n$. Execution steps grow proportionally with input size.
  • Quadratic Time ($O(n^2)$) : Algorithms containing nested loops (a loop within a loop). Execution steps grow quadratically with input size.
Complexity Analysis of Sorting Algorithms

All three sorting algorithms discussed in this chapter (Bubble Sort, Selection Sort, and Insertion Sort) utilize nested loops to perform comparisons and swaps. Consequently, they all exhibit a worst-case time complexity of $O(n^2)$.

Exercises & Case Studies

Exercise 1: Consider a list of 10 elements: randList = [7, 11, 3, 10, 17, 23, 1, 4, 21, 5]. Determine the partially sorted list after three complete passes of Bubble Sort.

Socio-Technical Analysis & Core Systemic Impact:
Let us trace the first three passes of Bubble Sort on the given list:
Initial: [7, 11, 3, 10, 17, 23, 1, 4, 21, 5]
Pass 1: The largest element (23) bubbles up to the end.
Trace: [7, 3, 10, 11, 17, 1, 4, 21, 5, 23]
Pass 2: The second largest element (21) bubbles up to the second-to-last position.
Trace: [3, 7, 10, 11, 1, 4, 17, 5, 21, 23]
Pass 3: The third largest element (17) bubbles up to its correct position.
Trace: [3, 7, 10, 1, 4, 11, 5, 17, 21, 23]
The partially sorted list after three passes is [3, 7, 10, 1, 4, 11, 5, 17, 21, 23] .
