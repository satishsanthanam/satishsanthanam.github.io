Class 12 (Part 3) — Chapter 4: Spatial Information Technology

Introduction to Spatial Information Technology

The disciplines that deal with the principles and methods of data processing and mapping using a combination of computer hardware and application software are referred to as Database Management System (DBMS) and Computer Assisted Cartography. Spatial Information Technology relates to the use of technological inputs in collecting, storing, retrieving, displaying, manipulating, managing, and analysing spatial information. It is an amalgamation of Remote Sensing, GPS, GIS, Digital Cartography, and Database Management Systems.

What is GIS (Geographical Information System)?

A Geographical Information System (GIS) is defined as a system for capturing, storing, checking, integrating, manipulating, analysing, and displaying data which are spatially referenced to the Earth. It involves a spatially referenced computer database and appropriate applications software.

Forms of Geographical Information

Geographical information is represented by two types of data: spatial data and non-spatial data (also called attribute data). Spatial data are characterised by their positional, linear, and areal forms of appearances.

Advantages of GIS over Manual Methods

Traditional maps have limitations such as fixed presentation formats, single or predetermined themes, and the requirement to redraw the entire map for any information updates. GIS offers several inherent advantages:

  • Users can interrogate displayed spatial features and retrieve associated attribute information.
  • Maps can be dynamically drawn by querying or analysing attribute data.
  • Spatial operations like polygon overlay or buffering can be applied to generate new information.
  • Different items of attribute data can be associated through a shared location code.
Components of GIS

The important components of a Geographical Information System include:

  1. Hardware: Processing, storage, display, and input/output sub-systems.
  2. Software: Modules for data entry, editing, maintenance, analysis, transformation, manipulation, and display.
  3. Data: Spatial and related tabular data (the backbone of GIS).
  4. People: Users ranging from software engineers to environmental scientists and policy-makers.
  5. Procedures: Methods for data retrieval, input, storage, management, analysis, and presentation.
Spatial Data Formats

Spatial data are represented in two primary formats: Raster Data Format and Vector Data Format.

Raster Data Format

Raster data represent graphic features as a pattern of grids of squares (cells). Each cell is assigned a position and an attribute value. The relationship between cell size and the number of cells is expressed as the resolution of the raster.

Vector Data Format

Vector data represent objects as points, lines, and polygons using precise coordinate pairs $(X, Y)$ or $(X, Y, Z)$. It is highly precise and ideal for individual map feature analysis.

Sequence of GIS Activities

The standard workflow involved in GIS-related work includes:

  1. Spatial Data Input: Acquiring digital datasets or creating them via manual input (digitisation/scanning).
  2. Entering of Attribute Data: Defining non-spatial properties of spatial entities.
  3. Data Verification and Editing: Identifying and correcting errors like data omissions, under/over shoots, and distortions.
  4. Spatial and Attribute Data Linkages: Matching datasets using Exact Matching, Hierarchical Matching, or Fuzzy Matching.
  5. Spatial Analysis: Processing data to extract meaningful geographic insights.
Spatial Analysis Operations

The analytical power of GIS is demonstrated through key spatial operations:

Overlay Analysis Operations

Overlay analysis integrates multiple thematic layers of maps of the same area to obtain a new map layer. It is widely used for land use/land cover change analysis and suitability modeling.

Overlay Equation:$$x + y = z$$Where $x = ext{Road map}$, $y = ext{Rail map}$, and $z = ext{Transportation map}$ (using the spatial overlay union operation).

Buffer Operation

Buffer operation creates a zone of a specified distance around any point, line, or area feature. It is used in proximity analysis to determine areas of influence, service coverage, or environmental impact zones.
