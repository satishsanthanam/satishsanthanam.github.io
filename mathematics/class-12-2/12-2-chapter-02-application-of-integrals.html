Mathematics: Class 12 (Book 2) — Chapter 2: Application of Integrals

Introduction & Fundamental Concepts

In geometry, standard algebraic formulae are used to compute the areas of simple rectilinear figures such as triangles, rectangles, trapeziums, and circles. However, these classical formulae are insufficient for determining the areas enclosed by arbitrary curves. Integral Calculus provides a systematic framework to evaluate these bounded regions using the concept of definite integration as the limit of a sum.

Area under Simple Curves

The area bounded by a continuous curve $y = f(x)$, the $x$-axis, and the vertical ordinates $x = a$ and $x = b$ can be conceptualized as the sum of an infinite number of infinitesimally thin vertical strips. Each elementary strip has an arbitrary height $y$ and an infinitesimal width $dx$.

  • Elementary Area Element: $dA = y \\, dx = f(x) \\, dx$
  • Total Area Formulation: The total area $A$ is obtained by integrating the elementary area $dA$ from the lower limit $a$ to the upper limit $b$:
$$A = \int_{a}^{b} dA = \int_{a}^{b} y \\, dx = \int_{a}^{b} f(x) \\, dx$$
Area Bounded with Respect to the Y-Axis

Alternatively, if the area is bounded by a continuous curve $x = g(y)$, the $y$-axis, and the horizontal lines $y = c$ and $y = d$, we construct horizontal elementary strips of width $dy$ and length $x$.

  • Elementary Area Element: $dA = x \\, dy = g(y) \\, dy$
  • Total Area Formulation:
$$A = \int_{c}^{d} x \\, dy = \int_{c}^{d} g(y) \\, dy$$
Sign Conventions and Absolute Value Rule

Since area is a geometric measure, it must always be non-negative. However, definite integrals can yield negative values depending on the position of the curve relative to the coordinate axes.

  • Curves Below the X-Axis: If $f(x) < 0$ for all $x \in [a, b]$, the definite integral $\int_{a}^{b} f(x) \\, dx$ will be negative. In such cases, we take the absolute value:
$$A = \left| \int_{a}^{b} f(x) \\, dx \right|$$
  • Alternating Sign Curves: If a curve crosses the $x$-axis within the interval $[a, b]$ (e.g., $f(x) < 0$ on $[a, c]$ and $f(x) > 0$ on $[c, b]$), the total area is computed by splitting the integration interval and summing the absolute values of each sub-region:
$$A = |A_1| + A_2 = \left| \int_{a}^{c} f(x) \\, dx \right| + \int_{c}^{b} f(x) \\, dx$$

Standard Geometric Enclosures & Derivations

Using the principles of definite integration, we can derive the standard area formulas for symmetric closed curves such as circles and ellipses.

Area of a Circle

The standard equation of a circle centered at the origin with radius $a$ is given by $x^2 + y^2 = a^2$. Due to symmetry across both coordinate axes, the total area is four \times the area of the region in the first quadrant.

Mathematical Problem Statement: Find the area enclosed by the circle $x^2 + y^2 = a^2$.

Step-by-Step Algorithmic Solution Trace:

  1. Express $y$ in terms of $x$ for the first quadrant ($x \ge 0, y \ge 0$):$$y = \sqrt{a^2 - x^2}$$
  2. Set up the integral for the first quadrant region bounded by $x = 0$ and $x = a$:$$A_{quadrant} = \int_{0}^{a} \sqrt{a^2 - x^2} \\, dx$$
  3. Apply the standard integration formula $\int \sqrt{a^2 - x^2} \\, dx = \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\sin^{-1}\left(\frac{x}{a}\right)$:$$A = 4 \times \left[ \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\sin^{-1}\left(\frac{x}{a}\right) \right]_{0}^{a}$$
  4. Evaluate the limits:
    • At upper limit $x = a$: $\frac{a}{2}\sqrt{0} + \frac{a^2}{2}\sin^{-1}(1) = \frac{a^2}{2} \left(\frac{\pi}{2}\right) = \frac{\pi a^2}{4}$
    • At lower limit $x = 0$: $0 + 0 = 0$
  5. Multiply by 4 to obtain the total area:$$A = 4 \times \frac{\pi a^2}{4} = \pi a^2$$

Final Evaluation Output: $A = \pi a^2$

Area of an Ellipse

The standard equation of an ellipse is $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$. Like the circle, it is symmetrical about both axes.

Mathematical Problem Statement: Find the area enclosed by the ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$.

Step-by-Step Algorithmic Solution Trace:

  1. Solve for $y$ in terms of $x$ for the first quadrant:$$y = \frac{b}{a}\sqrt{a^2 - x^2}$$
  2. Set up the integral for the total area using symmetry:$$A = 4 \int_{0}^{a} y \\, dx = 4 \int_{0}^{a} \frac{b}{a}\sqrt{a^2 - x^2} \\, dx$$
  3. Factor out the constants and integrate:$$A = \frac{4b}{a} \left[ \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\sin^{-1}\left(\frac{x}{a}\right) \right]_{0}^{a}$$
  4. Evaluate the limits:$$A = \frac{4b}{a} \left( \frac{a^2}{2} \cdot \frac{\pi}{2} - 0 \right) = \frac{4b}{a} \left( \frac{\pi a^2}{4} \right) = \pi ab$$

Final Evaluation Output: $A = \pi ab$

Advanced Applications & Piecewise Curves

When dealing with curves that cross the reference axis or are defined piecewise, we must partition the interval of integration to ensure that negative areas are correctly signed.

Linear Boundaries with Sign Alternation

Mathematical Problem Statement: Find the area of the region bounded by the line $y = 3x + 2$, the $x$-axis, and the ordinates $x = -1$ and $x = 1$.

Step-by-Step Algorithmic Solution Trace:

  1. Determine the $x$-intercept of the line $y = 3x + 2$:$$3x + 2 = 0 \implies x = -\frac{2}{3}$$
  2. Identify the sign of $y$ on the sub-intervals:
    • For $x \in \left[-1, -\frac{2}{3}\right]$, $y \le 0$ (below the $x$-axis).
    • For $x \in \left[-\frac{2}{3}, 1\right]$, $y \ge 0$ (above the $x$-axis).
  3. Set up the split definite integrals with absolute values:$$A = \left| \int_{-1}^{-2/3} (3x + 2) \\, dx \right| + \int_{-2/3}^{1} (3x + 2) \\, dx$$
  4. Find the antiderivative:$$F(x) = \frac{3x^2}{2} + 2x$$
  5. Evaluate the first integral:$$\int_{-1}^{-2/3} (3x + 2) \\, dx = \left[ \frac{3x^2}{2} + 2x \right]_{-1}^{-2/3} = \left( \frac{3(4/9)}{2} - \frac{4}{3} \right) - \left( \frac{3}{2} - 2 \right) = \left( \frac{2}{3} - \frac{4}{3} \right) - \left( -\frac{1}{2} \right) = -\frac{2}{3} + \frac{1}{2} = -\frac{1}{6}$$Taking the absolute value gives $\frac{1}{6}$.
  6. Evaluate the second integral:$$\int_{-2/3}^{1} (3x + 2) \\, dx = \left[ \frac{3x^2}{2} + 2x \right]_{-2/3}^{1} = \left( \frac{3}{2} + 2 \right) - \left( \frac{2}{3} - \frac{4}{3} \right) = \frac{7}{2} - \left( -\frac{2}{3} \right) = \frac{7}{2} + \frac{2}{3} = \frac{25}{6}$$
  7. Sum the two areas:$$A = \frac{1}{6} + \frac{25}{6} = \frac{26}{6} = \frac{13}{3}$$

Final Evaluation Output: $A = \frac{13}{3}$ square units

Trigonometric Wave Area Integration

Mathematical Problem Statement: Find the area bounded by the curve $y = \cos x$ between $x = 0$ and $x = 2\pi$.

Step-by-Step Algorithmic Solution Trace:

  1. Identify the roots of $y = \cos x$ in the interval $[0, 2\pi]$:$$x = \frac{\pi}{2}, \quad x = \frac{3\pi}{2}$$
  2. Determine the sign of $\cos x$ in each sub-interval:
    • $x \in \left[0, \frac{\pi}{2}\right]$: $\cos x \ge 0$
    • $x \in \left[\frac{\pi}{2}, \frac{3\pi}{2}\right]$: $\cos x \le 0$
    • $x \in \left[\frac{3\pi}{2}, 2\pi\right]$: $\cos x \ge 0$
  3. Set up the split integrals:$$A = \int_{0}^{\pi/2} \cos x \\, dx + \left| \int_{\pi/2}^{3\pi/2} \cos x \\, dx \right| + \int_{3\pi/2}^{2\pi} \cos x \\, dx$$
  4. Integrate each term (antiderivative is $\sin x$):
    • $\int_{0}^{\pi/2} \cos x \\, dx = [\sin x]_{0}^{\pi/2} = 1 - 0 = 1$
    • $\int_{\pi/2}^{3\pi/2} \cos x \\, dx = [\sin x]_{\pi/2}^{3\pi/2} = -1 - 1 = -2 \implies | -2 | = 2$
    • $\int_{3\pi/2}^{2\pi} \cos x \\, dx = [\sin x]_{3\pi/2}^{2\pi} = 0 - (-1) = 1$
  5. Sum the absolute values:$$A = 1 + 2 + 1 = 4$$

Final Evaluation Output: $A = 4$ square units

The development of integral calculus is one of the greatest achievements in mathematical history, evolving from ancient geometric approximations to rigorous modern analysis.
