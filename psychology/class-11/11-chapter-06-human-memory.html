Class 11 — Chapter 6: Human Memory

Introduction & Nature of Memory

Memory is conceptualised as a cognitive system consisting of three independent, though interrelated, stages: encoding, storage, and retrieval. Any information received by us goes through these stages.

The Three Stages of Memory

  • Encoding: The first stage where incoming sensory information is registered and recorded for the first time so that it becomes usable by the memory system.
  • Storage: The second stage where encoded information is retained and held over a period of time.
  • Retrieval: The third stage where stored information is recovered and brought back into conscious awareness for use in cognitive tasks.
Information Processing Approach: The Stage Model

Proposed by Atkinson and Shiffrin (1968), this model compares human memory to a computer system, processing information through three distinct memory stores.

Control Processes

Control processes monitor and guide the flow of information between different memory stores:

  • Selective Attention: Determines what information enters STM from sensory registers.
  • Maintenance Rehearsal: Repetitive silent or vocal rehearsal to keep information active in STM.
  • Chunking: Combining smaller units of information into larger, meaningful groups to expand STM capacity.
  • Elaborative Rehearsal: Connecting new information with existing knowledge in LTM to facilitate permanent storage.

Working Memory (Box 6.1)

Proposed by Baddeley (1986), Working Memory is an active workbench rather than a passive storehouse. It consists of three components:

  1. Phonological Loop: Holds and manipulates a limited number of sounds; decays within 2 seconds unless rehearsed.
  2. Visuospatial Sketchpad: Stores and manipulates visual and spatial information.
  3. Central Executive: Allocates attentional resources, coordinates the other components, and integrates information from LTM.
Levels of Processing

Proposed by Craik and Lockhart (1972) as an alternative to the Stage Model, suggesting that the durability of memory depends on the depth of processing.

Three Levels of Processing

  1. Physical/Structural (Shallowest): Focusing on the visual or structural features of a stimulus (e.g., whether a word is in capital letters).
  2. Phonetic (Intermediate): Focusing on the acoustic features and sounds associated with the letters (e.g., what the word rhymes with).
  3. Semantic (Deepest): Analyzing the meaning of the stimulus and connecting it to existing knowledge (e.g., defining the word or imagining its characteristics).
Types of Long-term Memory

Long-term memory is non-unitary and consists of structurally and functionally distinct systems.

Declarative vs. Procedural Memory

  • Declarative Memory: Memory for facts, names, dates, and events that can be consciously recalled and verbally described.
  • Procedural Memory: Memory for motor skills, habits, and procedures to accomplish tasks (e.g., riding a bicycle) which cannot be easily verbalized.

Episodic vs. Semantic Memory (Tulving)

  • Episodic Memory: Contains biographical details of our lives; personal experiences tied to specific times and places. These memories are often emotional in nature.
  • Semantic Memory: General awareness, concepts, ideas, rules of logic, and facts that are affect-neutral and not tied to a specific time or place.

Other Classifications (Box 6.2)

  • Flashbulb Memories: Highly detailed, vivid memories of extremely arousing or surprising events that feel like a frozen photograph.
  • Autobiographical Memory: Personal memories distributed unevenly across life, characterized by childhood amnesia during the first 4-5 years.
  • Implicit Memory: Memories that remain outside conscious awareness and are retrieved automatically, influencing behavior without conscious recall.
Methods of Memory Measurement

Different experimental methods are used to measure different types of memory systems:

  • Free Recall and Recognition: Used for declarative/episodic memory. Free recall requires generating items in any order; recognition requires identifying previously learned items among distracters.
  • Sentence Verification Task: Used for semantic memory; measures the speed of verifying true/false statements.
  • Priming: Used for implicit memory; measures how exposure to a stimulus influences subsequent performance on word-completion or identification tasks.
Nature and Causes of Forgetting

Forgetting is the inability to retrieve stored information from the memory system.

Ebbinghaus's Curve of Forgetting

Experiment Title: Ebbinghaus's Nonsense Syllables Study
Background/Subject: Hermann Ebbinghaus (1885) conducted experiments on himself.
Method/Procedure: Memorized lists of nonsense syllables (CVC trigrams like NOK or SEP) and measured the number of trials needed to relearn the lists at varying time intervals.
Observations/Results: Discovered a sharp, rapid drop in memory within the first nine hours (especially the first hour), after which the rate of forgetting stabilizes and declines very gradually.
Psychological Inference: Forgetting is not a linear process; the initial rate of memory loss is highly accelerated before plateauing.

Theories of Forgetting

  • Trace Decay (Disuse Theory): Assumes memory leaves physical traces in the brain that fade and decay over time if not used. (Inadequate because sleep reduces forgetting compared to waking activity).
  • Interference Theory: Forgetting is caused by competition between different associations stored in memory.
  • Retrieval Failure: Proposed by Tulving; forgetting occurs because appropriate retrieval cues are absent or inaccessible at the time of recall.

Repressed Memories (Box 6.4)

According to Sigmund Freud, painful, threatening, or traumatic memories are actively pushed down into the unconscious mind (repression) and become unavailable for conscious retrieval, sometimes leading to psychological amnesia or a fugue state.

Enhancing Memory (Mnemonics)

Strategies and techniques used to improve memory retention and retrieval.

Mnemonics using Images

  • The Keyword Method: Associating a foreign word with a similar-sounding native word, then creating a mental image of the two interacting.
  • The Method of Loci: Placing items to be remembered as visual objects along a familiar physical path or sequence of locations.

Mnemonics using Organisation

  • Chunking: Grouping smaller units into larger, meaningful structures.
  • First Letter Technique: Taking the first letter of each word to be remembered and arranging them to form an acronym (e.g., VIBGYOR).

Scientific Strategies for Memory Improvement

  1. Engage in Deep Level Processing: Focus on the meaning and establish associations with existing knowledge.
  2. Minimise Interference: Avoid studying highly similar subjects consecutively; distribute learning sessions with rest periods.
  3. Give Yourself Enough Retrieval Cues: Create cognitive links and contextual cues during encoding.
  4. The PQRST Method: A study method consisting of Preview, Question, Read, Self-recitation, and Test.
